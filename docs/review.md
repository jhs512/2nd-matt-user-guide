# 구현 확인 기준

교육용 005에는 다음 조건을 반영한 코드와 테스트가 포함됩니다.

- HTTP/H2, 화면, 실제 브라우저 검사로 공개 읽기와 관리자 작업을 확인합니다.
- 토큰은 메모리에 보관하고 공개 GET에는 Authorization을 보내지 않습니다.
- 저장 중 화면 이동으로 입력이 사라지지 않도록 관련 버튼을 비활성화합니다.
- 음수 페이지는 거절하고 전체 개수를 넘는 페이지는 빈 목록을 반환합니다.
- 실제 오류 상태, CORS, 제목·본문 검증과 생성 시간 보존을 확인합니다.

App.tsx는 작은 실습에서 화면과 API 호출을 함께 관리합니다. 기능이 커지면 분리를 검토할 수 있습니다.
